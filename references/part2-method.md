# Part 2 Method: Background → Main → Summary

## Structure

| Section | Time | What to do |
|---|---|---|
| **Background** | ~30s | Introduce the topic. Repeat the card words. Give context: Who/Where/When/Why. End with the modifier to set up your main points. |
| **Main Description** | ~60s | 2-3 points, each with description + evaluation. Connect with clear transitions. |
| **Summary** | ~30s | Overall feeling. Reflection or look forward. |

Total: ~120 seconds, 160-220 words.

## Card Analysis

Before you speak, check 3 things on the card:
- **Keywords** (red): What exactly are you describing? Don't drift.
- **Modifiers** (orange): What makes THIS topic different? The modifier is often the *real* question. Always return to it in your summary.
- **Tense** (blue): Past, present, or future? Wrong tense = lost points.

## Opening Phrases

- Ok, so I'm gonna talk about...
- Alright, so the topic I'm going to talk about is...
- Today I would like to talk about...
- I'd like to share something about...

Always repeat the topic card's key words in your first sentence.

## Content Expansion: 5W1H

| Section | 5W1H to use |
|---|---|
| Background | **Who** (with you?), **Where** (location?), **When** (time?), **Why** (reason?) |
| Main | **What** (happened? saw?), **How** (affect you? different?) |
| Summary | **Why** (meaningful?), **How** (influence now?) |

## Transitions Between Points

| Technique | Example |
|---|---|
| Ask & answer | *Whose home is it? Well, it's my best friend's place...* |
| As for... | *As for how often I go there, I'd say about once a week...* |
| Topic-shifting | *And about... / Talking about... / When it comes to... / And finally...* |

## Extending When You're Short

| Technique | Phrase |
|---|---|
| Add a detail | *Actually, there's one more thing worth mentioning...* |
| Add a feeling | *Another thing I'd like to add is how it affected me...* |
| Add a reflection | *Looking back now, I realize that...* |

## 1-Minute Prep Strategy

| Seconds | What to do |
|---|---|
| 0-10s | Read card. Underline keywords, modifiers, check tense. |
| 10-30s | Jot keywords: **B** (Background) / **1** / **2** / **F** (Feeling). 3-5 words each. |
| 30-50s | Mentally rehearse opening sentence. Modifier → main points connection. |
| 50-60s | Breathe. Review notes. Don't add anything new. |

## Summary Formula

Structure your summary with 3 parts:
1. **Positive**: What you liked, enjoyed, or appreciated
2. **Negative**: A small downside or challenge (shows balance)
3. **Pull back**: End on a positive note — would you do it again? Why it matters?

## Topic Merging（串题）

One well-prepared story can answer multiple cards. Adjust the angle and emphasis for each card's modifier.

## Common Mistakes

- Ignoring the modifier → The modifier IS the real question
- Going off-topic → Keep topic words in your notes
- Finishing too early (<90s) → Add a reflection or "another thing worth mentioning"
- Wrong tense → Past experience = past tense throughout
- All description, no feeling → Every point must include how you FELT
