# Part 3 Method: (TS+SD)×2

## Core

Part 3 uses TS+SD twice: **(TS+SD)×2**
- Two topic sentences, each with supporting details
- 5-8 sentences total, 40-60 seconds per answer
- Abstract, analytical, macro perspective

## Question Levels

| Level | Characteristics | How to Answer |
|---|---|---|
| **L1** | Direct, concrete, factual | Direct answer + 1-2 examples |
| **L2** | Reasons, comparison, some abstract thinking | (TS+SD)×2 full |
| **L3** | Abstract, social trends, analysis | (TS+SD)×2 full + deeper reasoning |

## Question Types: Facts vs Opinions

**Facts/Listing** → lean towards Reason&Example, Compare&Contrast
- Listing (What are the advantages of...?)
- Pros & Cons (What are the benefits and drawbacks...?)
- Comparison (How is A different from B?)
- Reasons (Why do people...?)
- Solutions (How can we...?)

**Opinions/Arguments** → lean towards Position&Counter, Evaluate&Judge, Predict&Speculate
- Agree/Disagree (Do you think...?)
- Evaluation (How important is...?)
- Prediction (How might... change in the future?)
- Analysis (How does A affect B?)

## 5 Types of SD

### 1. Reason & Example
**For**: Why…? / What causes…?
- TS: State judgment — *I think the main reason is…*
- SD: Reason (*This is because…*) + Example (*For instance…*)

### 2. Compare & Contrast
**For**: A vs B? / How is A different?
- TS: State key difference — *The main difference is… / Compared to the past,…*
- SD: Side A + Side B (describe each + why)

### 3. Predict & Speculate
**For**: Will…? / How might… change?
- TS: State prediction — *I think… will probably… / …is likely to…*
- SD: Logic (*Given that…*) + Consequence (*As a result,…*)

### 4. Evaluate & Judge
**For**: How important…? / To what extent…?
- TS: State evaluation — *I think… plays a key role in…*
- SD: Value (*It contributes to…*) + Consequence (*Without it,…*)

### 5. Position & Counter
**For**: Do you agree? / Some people think…
- TS: State position — *I would say… / I tend to agree that…*
- SD: Reason + Example → Counter (*Some might say…*) → Reclaim (*But I think…*)

## SD Pairing Strategies

| Strategy | When | Example |
|---|---|---|
| Same type ×2 | Listing multiple reasons | Both Reason+Example |
| Cause → Effect | Explain why, then so what | Reason → Predict/Evaluate |
| For → Against | Pros and cons | Reason+Example → Position+Counter |
| Present → Future | Now, then project forward | Compare+Contrast → Predict+Speculate |
| Surface → Deep | Obvious reason → deeper reason | Individual level → Societal level |

## From "Me" to "People"

This is THE key difference between Part 3 and Part 1.

| ❌ Part 1 style | ✅ Part 3 style |
|---|---|
| I think… | It seems that… / People tend to… / Generally speaking… |
| I do this because… | This happens because… / The reason behind this is… |
| For me… | For many people… / In most cases… / From a broader perspective… |

## Answer Depth

Always explain WHY, not just WHAT.
- ❌ Surface: "Technology helps people communicate faster."
- ✅ With reasoning: "Technology helps people communicate faster **because it removes the barriers of time and distance. In the past, you had to wait days for a letter; now, a message arrives instantly, which has fundamentally changed how relationships are maintained.**"
