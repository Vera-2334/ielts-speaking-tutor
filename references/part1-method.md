# Part 1 Method: TS + SD

## Core

- **TS (Topic Sentence)**: A clear, direct answer. Always answer the question first.
- **SD (Supporting Details)**: Extend with 2-3 SD types. 3-5 sentences total, 20-30 seconds.

## 4 Question Types

### 1. Yes/No Questions

**TS formula**: Always say Yes/No first.

| Instead of "Yes" | Instead of "No" | Neutral |
|---|---|---|
| Sure. / Absolutely. / Definitely. / Without a doubt. | Absolutely not. / Definitely not. / Not at all. / Not really. | It depends. / It's hard to say. / I'm not sure. |

### 2. Wh- Questions

**TS formula**: Answer the Wh- word directly.
- What → thing, Where → place, How often → frequency, When → time, Who → person, Why → reason

**Frequency words**: daily, most of the time, regularly, occasionally, once in a while, from time to time, hardly ever, once in a blue moon, rarely

### 3. Choice/Preference Questions

**TS formula**: Pick one (or both/neither), then explain WHY.
- Instead of "like": I enjoy, I'm fond of, I'm crazy about, I'm a big fan of, I'm really into, I'm passionate about
- Instead of "dislike": I can't stand, I can't bear, I'm not really into, It's not my thing

### 4. Hypothetical Questions

**TS formula**: Speculate naturally — use *if*, *might*, *maybe*, *probably*.
- Alternatives to "if": If I had the opportunity to…, Given the chance, As long as, Provided that, Supposing that

## 8 Types of SD

| SD Type | What it does | Signal words |
|---|---|---|
| **Reason** ★ | Explains WHY | because, since, the main reason is |
| **Example** ★ | Gives specific instance | for example, for instance, such as, like |
| **Opinion** ★ | What you think/feel | personally, I think, to be honest, honestly |
| **Description** | What something is like | — (just describe) |
| **Comparison** | How it differs | compared with, whereas, on the other hand |
| **Prediction** | What might happen | I think... will probably, I can see... in the future |
| **Result** | What happened as a consequence | as a result, so, this means that |
| **Reference** | What others say/know | people say, it's generally known that, research shows |

★ = most commonly used. Pick 2-3 that fit naturally.

## Answer Structure by Topic Type

| Topic Type | Example Questions | TS | Best SD Combo |
|---|---|---|---|
| 喜好 & 描述 | Do you like…? What's your favourite…? | 态度 / 点出对象 | Reason + Example + Opinion |
| 习惯 | How often do you…? Do you usually…? | 频率或习惯 | Description + Reason |
| 未来 | Would you…? Do you think you will…? | 打算或可能性 | Reason + Description |
| 经历 | Have you ever…? When was the last time…? | 是否/何时 | Example + Result + Opinion |

## Expansion Methods

### 5W1H
When stuck, ask: Why? Who? When? Where? How? What? Pick 2-3 that fit.

### Micro – Meso – Macro
- **Micro (Personal)**: Time, Money, Efficiency, Physical health, Mental health
- **Meso (Social circle)**: Friends, Family, Education, Colleagues, Community
- **Macro (Society)**: Economy, Society, Technology, Culture, Trends

## Common Linkers

| Function | Linkers |
|---|---|
| Examples | For example / For instance / Such as / Like / Especially |
| Reasons | Because / Since / As / The main reason is that |
| Opinions | I think / I feel / In my opinion / To be honest / Personally |
| Results | So / As a result |
| Adding | And / Also / Besides / In addition / What's more |
| Contrasts | But / However / On the other hand / Whereas / Although |

## Common Mistakes to Avoid

- One-word answers → Always TS + 2 SD minimum
- Repeating the question → Paraphrase, don't echo word-for-word
- Overly formal language → Part 1 = casual conversation
- Forgetting Yes/No first → Yes/No questions MUST answer in first sentence
- Memorized answers → Be natural, use the method not a script
